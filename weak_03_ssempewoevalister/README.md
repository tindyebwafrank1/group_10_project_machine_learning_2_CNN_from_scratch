# CNN Evaluation Metrics Suite

## Description
A modular, high-performance, header-only C++17 evaluation library designed to compute comprehensive classification performance metrics directly from raw convolutional neural network outputs. It establishes a multi-class confusion matrix and generates critical performance data including Accuracy, Precision, Recall, and F1 scores.

## Objectives
* Provide real-time inference tracking for deep learning evaluation pipelines.
* Ensure strict memory and error boundaries during multi-class validation.
* Deliver uniform interfaces matching downstream telemetry apps and preceding argmax classifiers.

## Main Features
* **Multi-Class Telemetry:** Supports multi-class classification setups (\(N \ge 1\) classes) via an optimized 1D flattened matrix layout.
* **Transactional Safety:** Validates entire evaluation mini-batches upfront to prevent partial, corrupting updates.
* **Resilient Edge-Case Management:** Safeguards macro averages and edge indicators against division-by-zero states.
* **Clean Formatting Output:** Built-in string serialization formatting for instant command-line or text log visualization.

## Requirements
* **Compiler:** `g++` or `clang++` supporting **C++17** standard flags (`-std=c++17`).
* **Build System:** CMake version $\ge 3.10$.

## Build Instructions

### Standard CMake Compilation Flow
```bash
mkdir build && cd build
cmake ..
make
```

### Standalone Manual Compilation Link
Because the library is entirely header-only, you can directly build it into a final execution unit without pre-compiling an explicit static module binary:
```bash
g++ -O3 -Wall -Wextra -std=c++17 main.cpp -o cnn_app
```

## How to Use the Library

```cpp
#include "cnn_library/metrics.hpp"
#include <iostream>
#include <vector>

int main() {
    // 1. Initialize a matrix for a 3-class setup (0, 1, 2)
    CNN::ConfusionMatrix cm(3);

    // 2. Sample ground truth and incoming pipeline predictions
    std::vector<size_t> actual    = {0, 0, 1, 1, 2, 2};
    std::vector<size_t> predicted = {0, 1, 1, 1, 2, 0};

    // 3. Process records 
    cm.add_batch(actual, predicted);

    // 4. Retrieve evaluation calculations
    std::cout << "Overall Accuracy: " << cm.accuracy() << "\n";
    std::cout << "Class 1 Precision: " << cm.precision(1) << "\n";

    // 5. Output comprehensive metrics console display table
    std::cout << cm.to_string();

    return 0;
}
```

## Limitations
* **Structural Domain Boundaries:** Supports only dense class index values strictly scaled from $0 \dots N-1$.
* **Missing Sampling Filters:** Does not offer micro-averaging, weighted averaging, or continuous analytical curve profiles like ROC/AUC.
